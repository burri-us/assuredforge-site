# Logos (version 2, 2026-11-21)

| File | Use |
|---|---|
| `tierra-wordmark.svg` | Tierra LLC wordmark for light backgrounds (ink and gold) |
| `tierra-wordmark-reversed.svg` | For dark backgrounds and the Tierra bar (`bar`), in both themes |
| `assuredforge-mark.svg` | AssuredForge mark for light backgrounds (ink peak, gold check) |
| `assuredforge-mark-reversed.svg` | For dark backgrounds and dark tiles |

The files have fixed colours (the asset store keeps no style rules inside an SVG). Theme switching happens where the marks are drawn inline in a page: the same paths, with `ink` and `gold` from the token variables, so they follow the light or dark theme by themselves. That is the standard practice for websites and products (README section 4); the files are the source record and serve documents, decks and email.
Colours: ink #0f2744 (dark theme #e8edf2); gold #b77a2f (dark theme #d29a52). The gold parts are graphics, never text.
The wordmark's text uses the system font in the file; drawn inline, it uses the brand face.
Use the files or their exact inline drawing; never redraw differently, recolour outside the tokens or stretch. Clear space and minimum sizes: README section 4.
