# Logos (version 2, 2026-11-21)

| File | Use |
|---|---|
| `tierra-wordmark.svg` | Tierra LLC wordmark on light or dark pages: follows the device's light/dark setting by itself |
| `tierra-wordmark-reversed.svg` | Always light: for dark bars such as the Tierra bar, whatever the theme |
| `assuredforge-mark.svg` | AssuredForge mark (ink peak, gold check): follows the device's light/dark setting by itself |
| `assuredforge-mark-reversed.svg` | Always light: for dark bars and dark tiles |

Pair the AssuredForge mark with "AssuredForge" in the display face for the product wordmark.
Colours are the design-system tokens (ink #0f2744 / dark #e8edf2; gold #b77a2f / dark #d29a52). The gold parts are graphics, never text.
The wordmark's text uses the system font (as on the live site); an SVG shown as an image cannot load the page fonts. An outlined version can follow if the brand needs the display face there.
Use the files as they are; never redraw, recolour or stretch. Clear space and minimum sizes: README section 4.
Version 1 fixed the AssuredForge mark's colours (no dark variant) and had no reversed versions; version 2 replaces it.
